### New Features and Improvements

* Expose `external_id` and `unity_catalog_iam_arn` computed attributes for `databricks_credential` resource with AWS IAM role ([#5285](https://github.com/databricks/terraform-provider-databricks/issues/5285)).

  The `databricks_credential` resource now exposes the `external_id` and `unity_catalog_iam_arn` attributes within the `aws_iam_role` block. These values are generated by Databricks during credential creation and can now be referenced directly in Terraform configurations, enabling automated setup of AWS IAM role trust policies without manual intervention.
